# Sistema de Recrutamento e Seleção

Projeto desenvolvido para a disciplina de **Programação Orientada a Objetos (POO)**. O sistema implementa um processo de recrutamento utilizando os princípios da orientação a objetos e operações de **CRUD (Create, Read, Update e Delete)**.

## Funcionalidades

- Cadastro de candidatos;
- Cadastro de vagas;
- Edição e remoção de vagas;
- Listagem de vagas;
- Candidatura a vagas;
- Listagem de candidaturas;
- Aprovação e rejeição de candidaturas;
- Agendamento e avaliação de entrevistas;
- Contratação de candidatos aprovados;
- Listagem de funcionários.

## Estrutura do Projeto

```
src/
├── Controller/
├── Model/
├── Repository/
├── View/
└── Main.java
```

- **Controller:** controla o fluxo da aplicação.
- **Model:** representa as entidades do sistema.
- **Repository:** realiza o armazenamento dos dados.
- **View:** interface de interação com o usuário via terminal.

## Objetivo

Este projeto foi desenvolvido para aplicar conceitos de Programação Orientada a Objetos, incluindo:

- Classes e Objetos;
- Encapsulamento;
- Associação entre objetos;
- Operações CRUD.
